Rádió69 – Remix és Hits lejátszásikonok

A csomag tartalma:
- index.html
- styles.css
- assets/partner-cold-warm.webp
- assets/partner-koha-sound.webp
- assets/partner-r-szita.webp

A Remix és Hits csatornaválasztó gombja előtt most jól látható, kör alakú ▶ ikon jelenik meg. Az aktív csatorna fehér hátterű, lila ikont kap; a másik fehér körvonalas ikont mutat.

GitHub feltöltés:
1. A repository gyökerében cseréld le az index.html és styles.css fájlokat.
2. A három partnerképet másold az assets mappába (ha már ott vannak, elég megtartani őket).
3. A script.js fájlhoz nem kell nyúlni.
4. Feltöltés után frissítsd az oldalt Ctrl+F5 billentyűkkel.

Megjegyzés: a csatornaválasztó gombok továbbra is a Remix és Hits csatorna közötti váltásra szolgálnak. A tényleges lejátszásindítás a külön Play gombbal történik.
